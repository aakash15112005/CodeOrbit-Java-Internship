# Simple Calculator Program

## About the Project
This is a simple console-based calculator developed using Java as part of my Java Programming Internship at CodeOrbit Tech.

The calculator performs basic mathematical operations based on the user's choice.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Menu-driven program using switch-case
- Repeats operations using do-while loop
- Handles division by zero using exception handling
- Handles invalid user input

## Technologies Used
- Java
- Eclipse IDE
- Scanner Class
- Exception Handling

## How to Run
1. Open the project in Eclipse IDE.
2. Open Calculator.java.
3. Run the program.
4. Select an operation from the menu.
5. Enter the required numbers.
